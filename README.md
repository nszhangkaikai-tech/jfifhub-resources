# JfifHub image conversion resources

This repository contains a small, reusable support matrix for browser-local JFIF conversion workflows.

JfifHub is a browser tool for converting JFIF-family images to JPG or JPEG. The conversion runs in the browser; image files are not uploaded to a server. Try the live tool at https://jfifhub.com/.

## Files

- `support-matrix.csv` — machine-readable input, output, quality, privacy, and batch behavior.
- `format-notes.md` — short notes for developers integrating a JFIF-to-JPEG step.

The matrix describes the behavior currently exposed by JfifHub’s public interface. Check the live page before depending on behavior in another product.
